# ADR 001 — Stack da aplicação

- **Status:** Em decisão pela equipe
- **Data:** outubro de 2026

## Decisões já estabelecidas

- PostgreSQL executado localmente com Docker.
- Nginx como proxy reverso.
- Docker Compose para orquestração local.

## Decisões pendentes

Antes do início da Sprint 2, a equipe deve registrar a linguagem/framework do
backend e frontend, ORM, migrations, autenticação, estratégia de testes, uso de
PostGIS versus Haversine e a versão fixa do PostgreSQL.

Alternativas e consequências devem ser adicionadas nesta página após a reunião
de aprovação.
