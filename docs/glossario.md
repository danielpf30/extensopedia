# Glossário, personas e atores

## Glossário

| Termo | Definição |
|---|---|
| Curricularização da extensão | Integração de atividades de extensão ao percurso curricular de estudantes. |
| IES | Instituição de Ensino Superior. |
| INEP | Instituto Nacional de Estudos e Pesquisas Educacionais Anísio Teixeira. |
| Lattes | Plataforma de currículos e grupos de pesquisa do CNPq. |
| Demanda | Necessidade educacional registrada por uma escola. |
| Projeto de extensão | Ação da IES voltada à interação transformadora com a sociedade. |
| Candidatura | Manifestação de interesse de uma IES em atender uma demanda. |
| MVP | Produto mínimo viável, com o menor conjunto de capacidades para validar a solução. |
