# 1. Introdução

## 1.1 Objetivo

O Extensopedia é uma plataforma web para conectar demandas de escolas públicas
a projetos de extensão e capacitação de instituições de ensino superior (IES).

## 1.2 Escopo inicial

O escopo documentado para a Sprint 1 contempla navegação pública, demandas
escolares, projetos para escolas, atendimento por IES, gestão de projetos e
administração. O comportamento detalhado deve seguir o PDF de requisitos
versionado junto deste documento.

## 1.3 Fonte normativa

`requisitos-v1.0.pdf` — levantamento de requisitos, outubro de 2026.

O arquivo ainda não está disponível neste checkout; a publicação dos requisitos
normativos está bloqueada até sua inclusão.
